# Processed data

Generated by the five analysis scripts and the compiled-figure notebook. These
files are reproducible and ignored by Git.

The release/uptake `modeling/` outputs retain culture-level kinetic fits and
add `k_per_od600` and `r_per_od600` for OD-specific figure summaries. The
`b12_rate_od_reference_b12_release_uptake_death.csv` table records matched
initial OD, final OD and their arithmetic mean for each culture/glucose
condition. See `docs/PIPELINE.md` for matching and validation rules.
