# Primary inputs

This directory contains the version-controlled inputs to the public pipeline:
byte-preserved instrument exports, curated strain and layout metadata, the
combined *E. coli*–*Chlamydomonas* assay dataset, KO counts, GWA summaries, and
the superseding 231-genome GTDB-Tk outputs.

Scripts must not modify these inputs. The only generated files under this tree
are the Git-ignored KEGG acquisition products documented in `annotations/`.
