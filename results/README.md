# Results

Generated figures, source/statistics tables, supplementary Tables S1–S3 and
self-contained compiled notebook. Figures 1–5 and S1–S19 are regenerated by
the production notebook. S12–S14 compare first-order and quota models; S16
contains the selected-strain rate phylogeny, and S17–S19 show gene associations,
bioassay comparison and survey fluorescence distributions. Manuscript captions
and Methods are maintained separately in Overleaf.

Figures 4B, 5B–C and S16 report OD-specific rates using each replicate's
mean initial/final blank-adjusted OD600; Figure 5D's k/r ratio is unchanged.

`compiled_figures/` contains 64 generated files: 26 PNGs, 26 PDFs, eight CSVs,
three XLSX workbooks and one HTML notebook. The image counts include two
intentional Figure 5 uptake subpanels under `additional_subpanels/`.
These generated outputs are ignored by Git.
