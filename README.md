# Bacterial vitamin sharing

Code and data supporting a manuscript on bacterial vitamin B12 synthesis, release, uptake and sharing.

## Repository status

This repository is under active development. The manuscript figure-generation notebook is available, while its documented input datasets and upstream processing workflows are being assembled.

## Structure

- `R/` — analysis and figure-generation code
- `data/` — manuscript input datasets
- `assets/` — non-R figure assets
- `docs/` — workflow and data-provenance documentation

## Figure generation

The main and supplementary manuscript figures are generated using:

`R/compiled_figures.Rmd`
